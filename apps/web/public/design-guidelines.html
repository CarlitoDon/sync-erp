Strict Color Rule: No Purple, Violet, or Indigo

Mandatory

Saturated purple and indigo gradients are strictly banned across all components, badges, gradients, and navigation. Sync ERP is an enterprise financial accounting and operations suite—not a recreational toy. We use high-contrast Monochrome Slate with a focused Deep Tech Blue primary action palette.

3. Vercel & Apple Best Practices (Do's & Don'ts)

Specific criteria evaluated during code reviews and UI audits.

✓

DO (Enterprise Standards)

  • • Tabular figures: Always format money and quantities with tabular-nums for clean vertical alignment.
  • • Punctuation & Copy: Use real unicode ellipsis … and specific action labels like "Create Company".
  • • Semantic HTML: Use genuine <button> and <a> for keyboard accessibility.
  • • Focus Rings: Explicit focus-visible:ring-4 focus-visible:ring-blue-500/15 on all inputs.
  • • Paste freedom: Never disable paste in inputs. Always allow users to paste bank numbers, tax IDs, and names.
×

DON'T (Strict Anti-Patterns)

  • • NO PURPLE / INDIGO: Do not use bg-indigo-600 or purple gradients.
  • • No transition: all: Always explicitly define transitioning properties (transition-colors or transition-transform).
  • • No clickable divs: Avoid <div onClick> without keyboard navigation handlers and role attributes.
  • • No missing labels: Never rely purely on placeholders. Placeholders disappear once text is typed.
  • • No generic buttons: Avoid vague words like "Submit" or "Click Here".
